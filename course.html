Course outcomes

What students should be able to do

1. Select

Identify real-world problems and select appropriate Generative AI tools.

2. Prompt

Apply prompt engineering techniques for accurate, context-aware output.

3. Compare

Identify and compare various Generative AI tools.

4. Create

Create text, images, presentations, and other digital content.

5. Use responsibly

Employ Generative AI tools ethically, responsibly, and securely.

Learning journey

From first prompt to responsible project work

AI basics

Understand Generative AI and the kinds of tasks it can support.

Prompt engineering

Learn to frame clear, useful, context-rich prompts.

Tool selection

Compare tools and choose based on the task.

Content creation

Work with text, images, presentations, and other formats.

Practical experimentation

Apply the ideas across the 14-week practical sequence.

Responsible AI

Verify output and use AI ethically, responsibly, and securely.
